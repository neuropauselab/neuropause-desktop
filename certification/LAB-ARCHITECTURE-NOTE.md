## THE CYCLE — recorded as direction

```
QUESTION AUDIT → DIM-1…DIM-12 → ANSWER AUDIT → EVIDENCE / LOGIC / CONTEXT
   → RESULT → VERIFY → MEASURE → CORRECT → REPRODUCE → AUTOMATE → REPEAT
```

**Naming, already binding (`ARCHITECTURE-MAPPING.md` §5.0):** the dimensional axes are **DIM-1…DIM-12**, never
`D-anything`. `DECISIONS.md` owns `D-1…D-16`, and "D-9 the decision" beside "D9 Governance the dimension" is the
**seventh** collision on a list that has predicted error more reliably than anything else in this programme.

**The dimensions are deliberately NOT enumerated here.** Mapping findings to dimensions is step 2's work, once the
axes have non-colliding names *and* the register exists to hold the mapping. Enumerating them now would produce a
taxonomy with nothing to classify.

## WHAT THE LAB WOULD CERTIFY

Not that a change was made, and not that a test passed. **That a stated improvement was reproduced** — the same
claim, re-established independently, under declared conditions, by someone who did not make the change.

That is a strictly stronger claim than anything the programme currently issues, and it sits at the end of the
register's own chain:

> CONSTITUTION → REQUIREMENT → IMPLEMENTATION → OBSERVATION → FINDING → CORRECTION → **VERIFICATION** → CLOSED

**The Lab would own VERIFICATION as a repeatable capability rather than a per-slice act.** Today verification is
performed once, by the same session that made the correction, and recorded in prose.

## WHAT MUST BE TRUE BEFORE THIS IS A PLAN — the entry conditions, stated so they can be checked

1. **One reproduction completed end to end.** Attempt 2, or any successor, run to a recorded result against a
   pre-registered decision tree.
2. **The register is schema'd and versioned** — the requirement already recorded in `CONTROL-REGISTER.md`. A Lab
   consuming a markdown section that grows would inherit F-P27's and F-P32's failure mode wholesale.
3. **DIM-1…DIM-12 named and stable.** A vocabulary that has moved between documents is a draft (§5.0's ruling on
   the evidence ladder), and a taxonomy is worth less than nothing while it moves.
4. **MEASURE has a source.** The cycle's MEASURE step needs a metric the programme actually computes; S35's
   relationship-observability metrics are roadmap, not landed.

**None of the four holds today.** That is the finding this note exists to record, and it is why the direction is
recorded rather than entered.

## THE HONEST BOUND

**This note describes an intention, not a capability.** It is filed here so that the intention is versioned,
diffable and reviewable — which is exactly what F-P27 established that intentions living in transcript are not.
**Recording a direction is not adopting it**, and adopting it is the operator's, after the four conditions above
can each be shown true.
