# Partner Platform

A directory of ecosystem partners across four types: **Technology Partners**,
**Consulting Partners**, **System Integrators**, and **Managed Service
Providers**. Partners are grouped by type, with tier (Registered / Select /
Premier), certification, specializations, regions, and listing counts.

## Honest seam

The directory is a **seeded representative set** of partners, persisted so it
stays stable. It is read-only in this stage — there is no partner application,
onboarding, or co-sell workflow yet. The types, tiers, and shape match a real
partner program so the surface is ready to be backed by a live partner registry.
