# Connector Marketplace

Browse and install connector listings, grouped by certification tier.

## Tiers

Three tiers are shown as badges and filters: **Community**, **Enterprise**, and
**Certified**. The tier is derived from existing listing data — a certified
listing is Certified, a paid listing is Enterprise, and a free listing is
Community — so the tiering reflects real signals rather than a separate stored
field. (Promoting tier to a first-class listing attribute is a natural follow-up.)

## Install lifecycle

Identical to the worker marketplace: install / update / enable / disable /
uninstall / rate, all tracked per organization through the installs store.

## IPC

Shares the Stage 2 installs channels and the Stage 1 `listings` + `rate`.
