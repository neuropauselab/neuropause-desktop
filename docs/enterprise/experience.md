# Enterprise Experience — Overview

> Phase 7, Stage 2 (Enterprise Experience). The executive-facing surfaces that
> render the Stage 1 Enterprise OS. **Renderer only — no new infrastructure.**

Stage 2 adds zero backend. Every surface reads the Stage 1 data layer and the
earlier phases through the existing typed `ipc` client. The whole experience
lives under `apps/desktop/src/renderer/src/enterprise/` and mounts behind a new
**Enterprise** section in the sidebar.

## One provider, live

`EnterpriseProvider` loads everything once, then keeps it current:

- **Initial load** — twelve parallel calls: the executive snapshot, org bundle,
  org graph, governance config, compliance findings, audit trail, workspaces,
  active workspace, workers, jobs, recommendations, and connector stats.
- **Live updates** — it subscribes to the **Platform Event Bus** plus the
  workforce and enterprise broadcasts. Any event triggers a **debounced (180 ms)**
  refresh. Enterprise events do a full refresh; workforce/platform events do a
  lighter refresh of the fast-moving slices (snapshot, compliance, audit, jobs,
  workers). Every widget on every surface updates without a manual reload.

## Business Operations

Organization-wide operational visibility, all from the snapshot + workforce +
governance + connector stats: AI utilization (jobs run, success), workforce
utilization (running/total, by role), project progress, connector health
(healthy/degraded/down), active workflows/jobs, governance metrics (pass rate,
chains/rules enabled, audit), productivity signals, and **trend analysis** — a
real 7-day job-count sparkline bucketed from job `createdAt` timestamps. Widgets
are configurable (see Customization).

## Executive Briefings

Morning Brief, Evening Summary, Weekly Review, Monthly Report — each generated by
`ipc.intelligence.briefing(period)`, which is deterministic and grounded in real
evidence. The panel renders the briefing's **facts** (grounded sections) and,
clearly separated below, **recommendations** labelled as suggestions, never as
fact. When there is no connected evidence, the report says so honestly rather than
inventing content.

## Enterprise Customization

Wired entirely to existing channels + renderer-local preferences:

- **Dashboards / KPI widgets** — inline per-surface widget toggles, remembered in
  `localStorage`; a reset control clears them.
- **Navigation** — choose which Enterprise sub-tabs appear (Command Center is
  always available); persisted and applied live.
- **Business units** — create / list / delete via `ipc.enterprise` org channels.
- **Roles** — list + create with permission scopes via `ipc.enterprise`.
- **Approval chains / Compliance rules** — toggle via `ipc.enterprise` governance
  channels.
- **Theme** — Auto / Light / Dark via the app theme channel.
- **Branding** — reflects the organization identity (full white-label lands later;
  the panel says so honestly).
