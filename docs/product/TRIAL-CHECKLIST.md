# NeuroPause — Trial Checklist

> **NeuroPause Global Product RC** · Documentation v1.0 · Product build `1.0.0-rc.15` (`0a040e2`) · Last updated 2026-08-08 · Audience: evaluators
>
> A suggested cadence (the operator sets the actual trial length). Tick items as you go; note anything that isn't obvious. Pairs with the [Trial Experience](TRIAL-EXPERIENCE.md).

## Day 1 — Set up & orient
- [ ] Backend up (`/health` = ok); org created; evaluators invited.
- [ ] Everyone signs in and reaches the shell.
- [ ] Read [Quick Start](../user/QUICK-START.md) + [Where Do I Go?](../user/WHERE-DO-I-GO.md).
- [ ] Complete [First 30 Minutes](../user/FIRST-30-MINUTES.md).
- [ ] Confirm you can tell **Today / Business / Advanced** apart, and open the Command Palette (⌘K).

## Day 2 — Operate on real data
- [ ] Pick 1–2 Business families you use (e.g. Finance, CRM, HR).
- [ ] Create, edit, and reopen records — confirm they persist locally.
- [ ] Check permissions behave (e.g. HR privacy gating).
- [ ] Save to AI Memory; retrieve via Knowledge search.

## Day 3 — AI & operations
- [ ] Configure an AI provider (or confirm the honest deterministic fallback).
- [ ] Run one governed AI Workforce action end-to-end; inspect approval + evidence.
- [ ] Review Operations health (confirm no false "Live").
- [ ] Connect one real integration in Connectors (or confirm honest "not configured").

## Day 7 — Extend & verticalize
- [ ] Browse AI Store; install/launch an app.
- [ ] Review Enterprise Marketplace (Preview) governance.
- [ ] Select your vertical's Industry pack (Preview); review its scope.
- [ ] Admin: review Administration, Settings (14 domains), and the security checklist.
- [ ] Developer: skim the [Developer Guide](../developer/DEVELOPER-GUIDE.md) + [API/SDK Guide](../developer/API-SDK-GUIDE.md).

## Final evaluation
- [ ] Local-first vs cloud vs external dependencies are understood.
- [ ] Acceptance criteria from the [Enterprise Pilot Guide](../enterprise/ENTERPRISE-PILOT-GUIDE.md) met.
- [ ] Known limitations reviewed (cold-launch auth, Preview surfaces, GUI QA, no public HTTP API).
- [ ] List of what to configure for production (providers, signing, secret management, backend hosting).
- [ ] Go / no-go decision recorded with rationale.
